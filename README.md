# a.saei.github.io
Abdullah Saei Webpage

## Setup

- Guidlines in [https://jekyllrb.com/docs/step-by-step/01-setup/]
- `gem install jekyll bundler`
- `bundle init`
- `jekyll new --skip-bundle . --force`
- `bundle install`

## Github-Pages Setup

- in Gemfile comment `gem jeykll` and uncomment `gem "github-pages"`
- run `bundle install` then `bundle update github-pages`

## To run the server locally

- `bundle exec jekyll serve`
